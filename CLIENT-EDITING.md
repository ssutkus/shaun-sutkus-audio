# Editing current clients

Open `client-data.js`. Each client has three values:

- `name`: the name displayed on the page
- `role`: Shaun's role for that client
- `url`: the client's official tour page

Edit only the text between quotation marks. To change the order, move an entire
client block, including its opening and closing braces. To remove a client,
delete that complete block and one adjacent comma.

The page automatically adds the separators, shared role line, links, and
Windows 95 hover styling.
